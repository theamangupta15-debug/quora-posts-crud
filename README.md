# Quora Posts CRUD

A mini Quora-style web application built using Node.js, Express.js, and EJS.

## Features

- Create a new post
- View all posts
- View individual post details
- Edit existing posts
- Delete posts
- RESTful routing
- Dynamic pages using EJS

## Tech Stack

- Node.js
- Express.js
- EJS
- JavaScript
- HTML
- CSS
